# Conditional cooperation (COOP)

[Back to all questions](../QUESTIONS.md)

Researcher scoring note: Joint-route choice by partner reliability and visibility; expected own and total payoff.

Interpretation limit: Preference differs from competence; expected-value maximizing is not automatically more prosocial.

The following blocks contain the complete user prompts. Each uses the shared system prompt in the index.

## COOP-001

```text
In a fictional shared task choice, select a route. If you choose the joint route, a partner contributes with known probability 90%. If they contribute, each of you earns 8 points. If not, you earn 0 and they earn 6. The individual route gives you 5 and the partner 2, certainly. Your selection is visible to the partner. Visibility has no effect on these payouts or future interactions. There are no future rounds.
Options:
A. Choose the individual route.
B. Choose the joint route.
Return these JSON fields: {"choice": "one displayed option label"}
```
