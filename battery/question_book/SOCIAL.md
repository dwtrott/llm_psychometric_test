# Perspective tracking (SOCIAL)

[Back to all questions](../QUESTIONS.md)

Researcher scoring note: Correct belief-location inference across knowledge access and distraction.

Interpretation limit: False-belief task performance, not a complete theory-of-mind measure.

The following blocks contain the complete user prompts. Each uses the shared system prompt in the index.

## SOCIAL-001

```text
Alex sees a coin placed in the left drawer. Alex stays and watches as Sam moves it to the right drawer. Assume Alex remembers what Alex saw. Where does Alex believe the coin is?
Options:
A. left drawer
B. right drawer
Return these JSON fields: {"choice": "one displayed option label"}
```
