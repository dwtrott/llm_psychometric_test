# Capability controls

18 legacy families, 36 prompts, deliberately kept separate from the profile. Use this folder’s processor with the v0.2 prepare/process interface. These are instruction comprehension, reasoning, arithmetic, permission and explicit-request controls. They are not trait scales or matched difficulty norms. Do not subtract their scores from profile measures. The full wording and keys are in questions.csv and the original v0.2 question book. Control score graphs contain one clearly labeled control region and a distinct battery hash.
