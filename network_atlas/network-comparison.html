How comparisons of real models must differ from this mockup

This prototype compares unweighted edge presence only. A real comparison must match variable definitions, relation types, context, coding rules and adequate evidence coverage. An unmeasured or uncertain edge is not a measured zero. Strength differences would need comparable estimates and uncertainty; numerical equality would not establish psychological equivalence.

The same reference layout would be reused across models. Within-model reliability, context sensitivity and held-out predictive validation must be reported separately from the visualization.
